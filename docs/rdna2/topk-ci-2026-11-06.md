## Fork CI

The fork's workflows only build and push the image (`docker-image.yml`) and
run lint (`pre-commit.yml`). `run-ci-command.yml` triggers the upstream
Buildkite pipelines and is gated on `github.repository_owner ==
'vllm-project'`. No fork workflow runs ROCm pytest and there is no self-hosted
GPU runner for it, so the coverage lands in the Buildkite YAML (it runs when
the branch is upstreamed or mirrored to the Buildkite AMD pipeline), and
nowhere else.
